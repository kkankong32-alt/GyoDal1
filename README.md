# 프롬프트 서재

『교실이 달라진다! 선생님을 위한 제미나이 노트북』의 독자용 프롬프트 저장소입니다.

## 실행

`index.html`을 브라우저로 열면 별도 설치 없이 사용할 수 있습니다. 링크 공유와 안정적인 클립보드 사용을 위해서는 웹 서버 또는 GitHub Pages로 접속하세요.

Python이 설치되어 있다면 이 폴더에서 `python -m http.server 8765`를 실행한 후 `http://localhost:8765`로 접속할 수 있습니다.

## 구성

- `index.html`: 페이지 구조, 책 소개, 표지, 사용 안내
- `styles.css`, `readability.css`: 반응형 디자인, 표지 입체 효과, 카드 조명·호버 효과
- `app.js`: 검색, 파트·챕터 필터, 정렬, 원문 복사, 상세 보기, 즐겨찾기, 개별 링크
- `data.js`: 5개 파트·16개 챕터·140개 프롬프트 및 본문 예시
- `assets/book-cover.png`: 표지시안 첫 번째 페이지를 렌더링한 이미지
- `assets/favicon.svg`: 사이트 아이콘
- `CONTENT_REVIEW.md`: 반영 기준 및 검증 내역

데이터의 `prompt`는 복사되는 책 원문이고 `title`, `tool`, `context`는 사이트에서 찾기 쉽게 정리한 안내입니다. `page`는 책에 인쇄된 쪽수이며 `pdfPage`는 검토용 펼침면 PDF의 페이지 번호입니다. 본문 PDF 전체는 사이트에 포함하지 않았습니다.

즐겨찾기는 현재 브라우저의 로컬 저장소에 보관됩니다. 로그인·서버·분석 추적은 없습니다. 저장소 사용이 차단된 환경에서는 현재 창에서만 유지됩니다. 검색은 입력한 단어가 모두 포함된 항목을 찾고, 현재 파트·챕터·즐겨찾기 필터와 함께 적용됩니다. `/` 키로 검색창에 바로 이동하고 `Esc`로 상세 보기를 닫을 수 있습니다. 운영체제의 동작 줄이기 설정을 존중합니다.

## GitHub Pages 배포

기존 `kkankong32-alt/GyoDal1` 저장소 루트에 위 파일들을 함께 반영하면 기존 주소를 유지할 수 있습니다. 상대 경로를 사용하므로 `/GyoDal1/` 하위 경로에서 동작합니다. 빌드나 npm 설치는 필요하지 않습니다. `index.html`만 올리지 말고 CSS·JS·assets 폴더를 함께 올리세요.

Google Fonts를 불러오지 못해도 시스템 글꼴로 표시되고 핵심 기능은 동작합니다.

## 읽기 편의성 개선

프롬프트는 넓은 1열 목록에서 전체 문장을 표시합니다. 본문은 데스크톱·모바일 모두 16px이며, 인쇄 원문의 문단과 목록 줄바꿈을 유지합니다. 제목 아래에 사용 안내를 표시하고 위·아래 복사 버튼을 제공합니다. 검색·필터·즐겨찾기와 개별 링크는 그대로 사용할 수 있습니다.
